# HarmonyOS 全量分类功能

## 背景

- 创建日期：2026-08-05
- 功能标识：`category-full-parity`
- 需求来源：iOS 分类功能设计白皮书；HarmonyOS 已有只读分类目录、任务卡片标签和主页 SideBar 的基础实现。
- 产品决策：保留既有搜索页和入口；分类管理放入主页的分类 SideBar，不新增浏览页或底部 Tab。

## 目标

- 任务和习惯均可选择、替换、清除或快速新建分类。
- 使用 KMP 作为分类的唯一业务与持久化权威，HarmonyOS 仅保留 DTO、桥接与展示逻辑。
- 首页 SideBar 支持“全部”“未分类”和多个分类的筛选，筛选同时作用于任务和习惯。
- SideBar 内完成新建、编辑和软删除分类；预设分类不可删除。
- 卡片以图标与名称展示可解析分类，分类色不改变任务状态色。
- 分类修改参与现有 ChangeLog/WebDAV 同步；读取或同步短暂失败时保留最后一次成功的目录快照。

## 非目标

- 不改造搜索页、搜索路由或 HdsTabs 信息架构。
- 不在任务或习惯分类选择器内编辑既有分类；编辑入口仅在主页 SideBar。
- 不引入新的云服务或重新设计同步协议。
- 不将分类色用于截止状态、进度或逾期状态。

## 用户场景

1. 用户在创建或编辑任务/习惯时，从预设或自定义分类中选择一项；也可以选择“未分类”。
2. 用户在选择器内快速创建“旅行”，创建成功后任务/习惯自动关联该分类。
3. 用户展开主页 SideBar，选择“全部”“未分类”或多个分类，任务和习惯视图立即同步过滤。
4. 用户在 SideBar 底部添加分类，并通过左滑编辑或软删除自定义分类；历史引用在分类删除后按未分类兜底，不丢失任务和习惯。

## 验收标准

- 分类目录包含八个预设分类，并能显示 KMP 持久化的自定义分类。
- 任务和习惯创建、编辑、清除分类后重新读取仍保留正确的 `categoryUid`。
- 更新习惯分类时，其 Harmony 兼容 Deadline 载体分类在同一 KMP 事务内同步更新。
- SideBar 的全部、未分类和多选分类对任务与习惯同时生效；“未分类”清除其他分类选择，且 `null`、缺失和历史空字符串分类值均被识别为未分类；分类被软删除或缺失时条目仍可在未分类下找到。
- 预设分类不可删除；自定义分类删除必须二次确认且使用软删除。
- 分类卡片标识只使用既有图标原语和分类颜色，不影响 Deadline 状态视觉。
- 分类 CRUD、软删除、同步后刷新、失败保留最近成功快照均有自动化或可重复手工验证记录。

## 风险与约束

- KMP 核心位于相邻 `ProjectDeadliner/DeadlinerCore`，分类写入 ABI、NAPI 和 Harmony lib 导入必须同步演进。
- 当前工作区含用户进行中的 SideBar 改动；不重置或覆盖无关改动。
- `Habit` ArkTS 投影当前没有 `categoryUid`，需先扩展模型与适配器，再接入 UI。
- 单个核心文件超过 1000 行前必须拆分或申请例外；现有大型页面只做最小接线。
